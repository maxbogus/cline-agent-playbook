# 10 — Текстовые скиллы: когда включать и когда они спят

> Это правило управляет набором «текстовых» скиллов. Они **по умолчанию
> выключены** и активируются ТОЛЬКО при генерации или редактуре текста.
> Во всех остальных задачах (код, инфраструктура, анализ данных) они не
> применяются.

## Набор текстовых скиллов

| Скилл | Включается, когда |
|---|---|
| `informational-style` | любой текст на написание или редактуру — базовый слой |
| `managed-sale` | продающий / убеждающий текст, скрипт продаж, КП, работа с возражениями |
| `cage-cover-letter` | сопроводительное письмо / отклик на вакансию в российскую компанию |
| `nlp-rapport` | текст или разбор коммуникации: переговоры, конфликт, сложный диалог |

## Триггеры включения

Включай текстовые скиллы, если задача — про текст для человека:

- «напиши текст», «составь письмо», «отредактируй», «сократи», «убери воду»,
  «перепиши», «сделай красиво».
- «сопроводительное письмо», «отклик на вакансию», «cover letter».
- «продающий текст», «коммерческое предложение», «скрипт продаж», «убедить».
- Любой запрос, где конечный результат — текст, который будет читать человек.

## Когда НЕ включать (скиллы спят)

- Код, конфиги, SQL, тесты, скрипты, миграции.
- Служебные сообщения: коммиты, PR-описания, логи, чат-ответы.
- Аналитика и отчёты, где важна фактура и структура, а не редактура «Пиши,
  сокращай» (если пользователь явно не просит переписать их в инфостиле).
- Любая задача, где текст не является конечным продуктом для человека.

## Порядок применения

1. Определи тип текста: письмо / продажа / переговоры / просто текст.
2. Подключи базовый `informational-style` (факты вместо оценок, убрать воду,
   меньше канцелярита).
3. Поверх добавь профильный скилл по типу задачи:
   `cage-cover-letter` / `managed-sale` / `nlp-rapport`.
4. Перед сдачей пройди чек-лист выбранного скилла.

## Важно

- Скиллы не «всегда включены» в фоне. Если запрос не про текст — не тяни их в
  ответ и не навязывай редактуру там, где просят код или данные.
- Если задача смешанная (например, «напиши README»), применяй
  `informational-style` к текстовой части, но не переписывай код и команды.
